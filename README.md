# Engenharia de Dados — Estudos

Repositório de estudos práticos em engenharia de dados, usando **Databricks** e **Python**.

Aqui registro minha jornada de aprendizado enquanto migro de QA e análise de dados para engenharia de dados. É um caderno vivo: notebooks, testes e anotações que vou acumulando conforme estudo. A ideia não é ter tudo perfeito ou organizado, e sim manter o histórico do que fui aprendendo e praticando.

## O que você encontra aqui

Estudos e experimentos em Python voltado para dados, PySpark, SQL, modelagem e pipelines — desenvolvidos no Databricks Free Edition e versionados aqui pra acompanhar a evolução ao longo do tempo.

## Stack

Databricks · Python · PySpark · SQL · PostgreSQL
